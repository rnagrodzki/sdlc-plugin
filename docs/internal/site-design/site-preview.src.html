sdlc FlowSkillsDocsRelease notes

One pipeline from idea to merged pull request.

sdlc is a plugin for Claude Code. It plans the work, builds it in waves, commits, reviews, opens the pull request and checks CI. You watch every run on one dashboard.

Install in Claude Code

/plugin marketplace add rnagrodzki/sdlc-plugin/plugin install sdlc@sdlc-plugin
Sample run feat/gh-pages 6 h 12 min
  1. Preplan/sdlc:preplan20 decisions
  2. Plan/sdlc:plan14 tasks
  3. Execute/sdlc:execute3 of 3 waves
  4. Commit/sdlc:commitdone
  5. Review/sdlc:review4 of 6 dimensions
  6. Pull request/sdlc:prwaits
  7. Verify/sdlc:verify-pipelinewaits

/sdlc:ship runs execute to pull request in one command, and can verify CI. Harden turns a failed run into a new guardrail for the next plan.

Every run on one page.

The dashboard shows each pipeline step by step, with the time of every step and the open issues.

  • Dashboard

    One page shows every pipeline in every repository: progress, session activity and issues.

  • Stats

    Each run records how long every step took.

  • Harden

    After a failed run, harden proposes a new guardrail, so the same failure does not return.

  • Long runs

    A pipeline can run for hours or days. A stopped run resumes where it stopped.
